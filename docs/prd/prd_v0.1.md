# PRD — 헬스 기구 사용법 안내 AI ver.0.1

**작성일:** 2026-10-27 · **노션:** 팀 산출물 › 9주차 (프로젝트 기획서 ver.0.1, 실습 4)

> 9주차 프로젝트 기획서 전체(개요 · 문제 근거 · 차별성 · 위험 요소 등)와 실습 1 유저 스토리, 실습 2 기능 우선순위, 실습 3 IA는 노션 9주차 페이지에 있습니다. 이 파일은 그중 실습 4 PRD ver.0.1입니다.

---

## 1. 프로젝트 소개

### 헬스 기구 사용법 안내 AI

| 항목 | 내용 |
| --- | --- |
| 프로젝트 목표 | 운동 부위에 맞는 헬스 기구를 추천하고 사용법을 안내한다. |
| 프로젝트 유형 | AI 모델 구현 실습 중심 |
| 핵심 아이디어 | 사용자가 운동 부위를 선택하면 관련 기구를 추천한다. |
| 개발 방향 | 규칙 기반 추천과 직접 학습한 AI 모델의 결과를 비교한다. |
| 사용 환경 | 모바일 웹 |
| 주요 제약 | 유료 LLM 요금제와 필수 유료 API를 사용하지 않는 방향으로 진행한다. |

## 2. 사용자·문제·가치

- **목표 사용자:** 헬스 기구 사용법을 잘 모르는 초보자
- **해결하려는 문제:** 운동 부위에 맞는 기구를 고르거나 사용법을 찾기 어려울 수 있다.
- **제공할 가치:** 운동 부위에 맞는 기구와 기본 사용법을 쉽게 확인할 수 있다.
- **확인된 사실:** 위 내용은 현재 프로젝트의 기획 방향이다.
- **검증할 가설:** 실제 초보자도 이러한 불편을 겪는지, 추천 서비스가 도움이 되는지 확인해야 한다.

## 3. 만들 범위

| 기능 | 등급 | 내용 |
| --- | --- | --- |
| 운동 부위 선택 | Must Have | 가슴·등·어깨·하체·팔 중 원하는 부위를 선택할 수 있음 |
| AI 기구 추천 | Must Have | 선택한 운동 부위와 관련된 기구 목록이 표시되고, 추천 결과가 없을 경우 안내 메시지가 표시됨 |
| 기구별 타깃 근육 및 운동 목적 안내 | Must Have | 추천된 각 기구의 이름, 주요 타깃 근육 및 운동 목적이 표시됨 |
| 기구 사용법 및 주의사항 안내 | Must Have | 기구별 세팅 방법, 사용 순서, 주의사항 및 참고 출처를 확인할 수 있음 |
| 모델 성능 평가 | Must Have | 테스트 데이터에 대한 평가 결과와 오추천 사례를 확인할 수 있음 |
| 운동 부위 변경 및 재추천 | Should Have | 기존 화면에서 운동 부위를 변경하고 새로운 추천 결과를 확인할 수 있음 |
| 기구 사진 인식 | Won't Have This Time | 사진 업로드 및 이미지 분류 기능을 구현 범위에서 제외함 |
| 생성형 AI 대화형 상담 | Won't Have This Time | 별도 LLM 연동 없이 구조화된 기구 정보와 추천 모델만으로 핵심 기능을 제공 |

## 4. 구조·사용 순서

### 4-1. 화면 구성

| 화면 ID | 화면명 | 주요 기능 | 우선순위 |
| --- | --- | --- | --- |
| SCR-001 | 메인 화면 | 서비스 소개 및 시작 | 기본 |
| SCR-002 | 운동 부위 선택 | 원하는 운동 부위 선택 | 필수 |
| SCR-003 | AI 추천 결과 | 관련 기구 목록 확인 | 필수 |
| SCR-004 | 기구 상세 정보 | 주요 근육, 운동 목적, 사용법, 주의사항 확인 | 필수 |
| SCR-005 | 운동 부위 변경 | 부위를 바꾸고 다시 추천받기 | 추가 고려 |
| SCR-006 | 전체 기구 목록 | 등록된 기구 확인 | 추가 고려 |
| SCR-008 | 모델 평가 결과 | 기준선과 학습 모델 비교 | 개발·시연용 |
| SCR-009 | 오류 안내 | 추천 결과가 없거나 데이터 조회에 실패한 경우 안내 | 예외 처리 |

### 4-2. 사용자 이용 순서

① 메인 화면 (서비스 시작) → ② 운동 부위 선택 (가슴 · 등 · 어깨 · 하체 · 팔) → ③ 추천 결과 확인 (관련 헬스 기구 목록) → ④ 기구 상세 정보 확인 (주요 근육 · 운동 목적 · 사용법 · 주의사항)

## 5. 기능 설명

| 기능 | 설명 | 구현 방향 |
| --- | --- | --- |
| 운동 부위 선택 | 사용자가 원하는 운동 부위를 선택한다. | HTML·CSS·JavaScript |
| 기구 추천 | 선택한 부위와 관련된 기구를 추천한다. | 규칙 기반 추천 및 학습 모델 |
| 기구 정보 표시 | 기구의 주요 근육과 운동 목적을 보여준다. | CSV 또는 JSON 데이터 활용 |
| 사용법 안내 | 기본 사용 순서와 주의사항을 보여준다. | 출처를 확인한 기구 정보 활용 |
| 모델 성능 비교 | 규칙 기반 추천과 학습 모델의 결과를 비교한다. | Python, pandas, scikit-learn |
| 모바일 웹 연동 | 웹 화면에서 추천 결과를 확인한다. | Flask 활용 검토 |
