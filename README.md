# 머신메이트 · 헬스 기구 추천 프로토타입 (ver04)

## 실행 방법 (중요)

데이터를 JSON 파일(`data/*.json`)로 불러오기 때문에 **index.html을 더블클릭하면 실행되지 않습니다.**
브라우저 보안 규칙상 `file://` 주소에서는 JSON 파일을 읽을 수 없기 때문입니다. 로컬 서버로 실행해 주세요.

**방법 1. VS Code Live Server (추천)**
1. VS Code에서 이 폴더(`machinemate_ver04`)를 엽니다.
2. 확장 프로그램 **Live Server**를 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 누릅니다.

**방법 2. 파이썬**
```
cd machinemate_ver04
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속

## 폴더 구조

```
machinemate_ver04/
├── index.html              화면 구조 (HTML)
├── css/
│   └── style.css           디자인
├── js/
│   ├── data.js             JSON 데이터 불러오기
│   ├── storage.js          브라우저 저장소(localStorage) 도우미
│   ├── auth.js             로그인 · 회원가입 · 마이페이지
│   ├── plan.js             내 계획표 (추가 · 완료 체크 · 삭제)
│   ├── share.js            스케줄 공유 (목록 · 좋아요 · 저장 · 내 계획표 공개)
│   └── app.js              화면 이동 · 하단 탭 · 부위 선택 · 추천 결과
├── data/
│   ├── exercises.json      운동 부위별 추천 예시 데이터 (6개 부위 × 3개 = 18개 기구)
│   └── shared_plans.json   스케줄 공유 예시 데이터 (예시 사용자 계획표 4개)
└── assets/
    └── images/             기구 사진 18장 (.jpg, 파일 이름 = 데이터의 id)
```

## 하단 탭과 화면

| 탭 | 화면 |
|---|---|
| 홈 | 서비스 소개, 운동 부위 고르기 → 부위 선택 → AI 추천 결과 |
| 네비게이션 | 운동 부위를 누르면 바로 AI 추천 결과로 이동 |
| 스케줄 공유 | 다른 사용자의 계획표 목록(인기순·최신순), 상세 보기, 좋아요, 내 계획표에 저장 |
| 마이페이지 | 로그인 · 회원가입, 프로필, 이번 주 통계, **내 계획표**, 내 계획표 공유 설정, 로그아웃, 회원 탈퇴 |

## 저장 방식 (시연용)

- 서버가 없는 프로토타입이라 계정 · 계획표 · 좋아요를 **이 브라우저의 localStorage**에 저장합니다.
- 비밀번호는 그대로 저장하지 않고 SHA-256 해시로 바꿔서 저장합니다.
- 로그인하지 않고 담은 기구는 로그인하거나 가입하면 내 계획표로 옮겨집니다.
- 좋아요와 계획표 저장은 로그인이 필요합니다. 내 계획표에는 좋아요를 누를 수 없습니다.
- 마이페이지에서 "스케줄 공유에 내 계획표 올리기"를 켜면 같은 브라우저의 다른 회원이 볼 수 있습니다.
- 실제 서비스에서는 서버(예: Flask)와 데이터베이스에서 관리해야 합니다.
